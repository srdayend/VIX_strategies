# FIXERS Baseline Archive

The original 2026 Spring FIXERS project is treated as **Baseline v0**.

The GitHub state before thesis refinement is frozen on branch:
`archive/fixers-baseline-v0`

Additional historical artifacts are stored outside GitHub as immutable source files:
- original presentation,
- evidence package,
- VIX.zip legacy backtest package,
- VIX futures / VIX spot Excel files.

The thesis branch must not overwrite historical outputs or silently reinterpret them as current results.

Legacy code from `VIX.zip` will be copied under this archive namespace only when it is needed for lineage checks; it is not the canonical thesis engine.
